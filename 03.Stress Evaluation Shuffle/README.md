This folder contains the Python code and results for the stress evaluation where the multiple-choice answers were randomly shuffled (re-ordered).

- **Original_VS_Stress.ipynb:** Notebook used to compute the results and compare the original tests with the test where the multiple-choices were shuffled.
- **Results.xlsx:** Summary of the results (main table in the manuscript).
- **combined_exam_dataset_shuffled.ipynb:** Code to generate the dataset with the multiple-choices shuffled.
- **combined_exam_dataset_shuffled.pkl:** Dataset with the multiple-choices shuffled.
