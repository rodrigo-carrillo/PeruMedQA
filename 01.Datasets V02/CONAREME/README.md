This folder contains the original examinations and the code used to build version 2 of the dataset.

Each year has a corresponding folder with:
- PDFs containing the original examinations downloaded from the CONAREME (Consejo Nacional de Residentado Médico) website: https://www.conareme.org.pe/web/.
- `<exam>.csv` and `<exam>.json` files: the parsed exam, generated by `process_exams.py`.

The number of PDF, CSV and JSON files is equal to the number of examinations (100 in total).

Other files:
- `process_exams.py` and `consolidate_exams.py`: the pipeline, described below.
- `answer_overrides.csv`: human corrections, applied by `process_exams.py`. It is currently empty, because no correction was needed.
- `_backup_csv_verificados/`: the version 1 CSVs, produced by the legacy notebooks and verified by a human. `process_exams.py` uses them as the reference for its verification.
- `discrepancias_con_version_1.md` / `.csv`: every difference between version 1 and version 2, together with the human verification (2026-11-11). In Spanish.
- `logs/`: processing and consolidation logs, the verification report and the human-review list.

## Pipeline

Requirements: Python 3 with PyMuPDF, pandas and pyarrow.

### 1. `process_exams.py`: extract every exam

```
python3 process_exams.py                  # all years; writes <exam>.csv + <exam>.json next to each PDF
python3 process_exams.py --dry-run        # only log + reports, writes nothing
python3 process_exams.py --years 2024 --exam "CIRUGÍA"
python3 process_exams.py --render-review  # PNG crop of every question flagged for review
```

- Questions and options are parsed across the whole document. This handles two-column options, multi-line options, column flow and questions that cross pages. Page headers and footers are removed. Text is cleaned to a single line.
- The correct answer is the yellow highlight. Two independent methods (vector rectangles and rendered pixels) must agree.
- Coverage check: every non-blank character of the PDF body must appear in the output, and nothing may be added.
- Comparison with the human-verified CSVs in `_backup_csv_verificados/YearXXXX/<exam>.csv`. The script checks answers and the text similarity of every field.
- `answer_overrides.csv` holds human corrections, applied after extraction. Columns: `year, exam, question_number, field, value, reason`, where `field` is `correct_answer`, `questions` or `option_X`.
- Outputs in `logs/`:
  - `procesamiento_<stamp>.log`
  - `reporte_verificacion_<stamp>.json`
  - `revision_humana_<stamp>.csv`, with one row per item for human review
  - `review_png_<stamp>/`

Per-exam CSV columns: `question_number, questions, option_A … option_D[, option_E], correct_answer`. There are 5 options for 2018–2022 and 4 for 2023–2026.

### 2. `consolidate_exams.py`: merge all exams

```
python3 consolidate_exams.py --output-dir ..   # writes the conareme_master_* files to "01.Datasets V02/"
```

Without `--output-dir`, the script writes to `../00_Datasets/`.

- `conareme_master_5opciones.{csv,json,parquet}`: all exams have 5 options. For the 4-option exams, `option_E = "Ninguna de las anteriores"`.
- `conareme_master_opciones_originales.{csv,json,parquet}`: each exam keeps its original options. For the 4-option exams, `option_E` is empty (missing).
- `conareme_master_validation.json`: quality checks and warnings, described in `../README.md`.
- `logs/consolidacion_<stamp>.log`.

Columns: `question_id, year, exam, exam_type, exam_title, specialty, question_number, n_options_original, questions, option_A … option_E, correct_answer, has_image, flags`.
